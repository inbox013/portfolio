## 🎯 Зачем я создал этот сайт

1. **Современная визитка:** Резюме в PDF — это хорошо, но личный сайт позволяет показать меня с другой стороны, продемонстрировать мой вкус, подход к структурированию информации и знание современных веб-трендов.
2. **Демонстрация навыков:** Сайт написан на чистом стеке (HTML, CSS, Vanilla JS) без использования тяжелых фреймворков. Это обеспечивает мгновенную загрузку, высокую производительность и отличные показатели Core Web Vitals.
3. **Проверка гипотезы:** Мне было интересно создать стильный, адаптивный лендинг, используя актуальный тренд **Editorial Style** (крупная типографика, акцент на контенте, сдержанная палитра).

## 🤖 Как я это сделал (и почему не скрываю использование ИИ)

Этот проект — **яркий пример моего подхода к работе с современными инструментами (AI-Assisted Development)**. 

Я считаю, что в 2026 году умение использовать нейросети для генерации кода, структурирования данных и создания каркаса проекта — это **обязательный навык для веб-разработчика**, а не читерство.

**Мой процесс выглядел так:**
*   **Анализ и ТЗ:** Я провел ресерч трендов (вдохновлялся сайтами вроде roman-fedoseev.com), выбрал шрифтовые пары и цветовую палитру.
*   **Промпт-инжиниринг:** На основе моего резюме я составил детальный запрос для ИИ, чтобы сгенерировать структуру `index.html`, стили `style.css` и логику анимаций `script.js`. ИИ выступил в роли моего «младшего разработчика».
*   **Ревизия и адаптация:** Я проверил сгенерированный код, убедился в его валидности, адаптивности (mobile-first) и оптимизировал под деплой на GitHub Pages.

**Почему я указываю это в README?**
Потому что при отклике на вакансии я хочу показать будущему работодателю, что я:
1. Не боюсь новых технологий.
2. Умею делегировать рутину ИИ, экономя время на бизнес-логике.
3. Способен контролировать качество сгенерированного кода и доводить его до продакшена.

## 🛠 Технический стек проекта

*   **HTML5** — семантическая разметка.
*   **CSS3** — кастомные свойства (переменные), Grid, Flexbox, адаптивная вёрстка (медиа-запросы).
*   **Vanilla JavaScript** — легковесный скрипт на базе `IntersectionObserver` для плавного появления секций при скролле.
*   **GitHub Pages** — хостинг для статических сайтов.
